Dev journal / roadmap

Small steps. Clear progress.

Boxed is in development. This page shares the work's current direction and intended next milestones without promising dates before the game is ready.

Development direction

From a rule to a world.

Current focus

Define the puzzle language

Settle the basic movement, block, and switch rules so each room teaches clearly and behaves consistently.

Next milestone

Build a playable slice

Turn a small set of room concepts into a prototype, then test whether the puzzle ideas work in play.

Looking ahead

Explore PC and mobile

Evaluate controls, screen layouts, and performance for both target platforms before sharing a release plan.

Milestones describe development intent. No release date or public build is announced.
